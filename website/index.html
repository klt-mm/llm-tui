LLM-TUI

A local-first, keyboard-driven terminal UI client for llama.cpp and OpenAI-compatible LLM endpoints

Get Started View on GitHub

Features

🚀 Local-First

Works seamlessly with llama.cpp and any OpenAI-compatible endpoint. Your data stays local.

⌨️ Keyboard-Driven

Full keyboard navigation with vim-style bindings. Fast and efficient workflow.

💾 Persistent Storage

SQLite database with FTS5 full-text search. Never lose your conversations.

🔧 Tool Calling

Built-in tools for shell commands, file operations, and more. Extensible tool system.

🖼️ Vision Support

Attach images to your messages. Works with vision-capable models.

📊 Context Engineering

Smart token budgeting and context management. Optimize your prompts.

🔍 Full-Text Search

Search across conversations and prompts with FTS5. Find anything instantly.

🌿 Branching

Branch conversations and edit as branch. Explore different conversation paths.

Quick Start

# Install LLM-TUI
curl -fsSL https://raw.githubusercontent.com/klt-mm/llm-tui/main/install.sh | bash

# Or build from source
git clone https://github.com/klt-mm/llm-tui.git
cd llm-tui
cargo build --release

# Run
./target/release/llm-tui

See the Installation Guide for more options.

Architecture

TUI (ratatui)
  ↓
Application / Services (app.rs, events.rs)
  ↓
Domain (src/domain/)          ← must not import ratatui, sqlx, reqwest, or terminal APIs
  ├── LLM Provider (src/llm/)
  └── Repositories (src/persistence/)
        ↓
      SQLite + FTS5

Tech Stack

  • Language: Rust (edition 2024)
  • TUI: ratatui + crossterm
  • Async runtime: tokio
  • Database: SQLite via sqlx (with FTS5 full-text search, migrations)
  • HTTP / Streaming: reqwest (rustls-tls, streaming SSE)
  • Serialization: serde / serde_json
  • Error handling: thiserror + anyhow
  • Logging: tracing + tracing-subscriber (env-filter)
  • IDs: uuid v4
