Installation Guide

Quick Install (Recommended)

The easiest way to install LLM-TUI is using our installation script:

curl -fsSL https://raw.githubusercontent.com/klt-mm/llm-tui/main/install.sh | bash

This will automatically detect your system and install the appropriate binary.

Build from Source

If you prefer to build from source or need a specific version:

Prerequisites

  • Rust 2024 edition or later
  • Git
  • SQLite development libraries

Installation Steps

# Clone the repository
git clone https://github.com/klt-mm/llm-tui.git
cd llm-tui

# Build in release mode
cargo build --release

# The binary will be at ./target/release/llm-tui
# Optionally, copy it to your PATH
sudo cp ./target/release/llm-tui /usr/local/bin/

Platform-Specific Instructions

Linux (Ubuntu/Debian)

# Install dependencies
sudo apt-get update
sudo apt-get install -y build-essential pkg-config libssl-dev git sqlite3 libsqlite3-dev

# Install Rust (if not already installed)
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source $HOME/.cargo/env

# Build and install
git clone https://github.com/klt-mm/llm-tui.git
cd llm-tui
cargo build --release
sudo cp ./target/release/llm-tui /usr/local/bin/

macOS

# Install dependencies with Homebrew
brew install rust sqlite

# Build and install
git clone https://github.com/klt-mm/llm-tui.git
cd llm-tui
cargo build --release
sudo cp ./target/release/llm-tui /usr/local/bin/

Android (Termux)

# Install dependencies
pkg install rust git sqlite

# Build and install
git clone https://github.com/klt-mm/llm-tui.git
cd llm-tui
cargo build --release
cp ./target/release/llm-tui $PREFIX/bin/

Windows

Windows support is experimental. You'll need:

  • Rust toolchain (via rustup)
  • Visual Studio Build Tools
  • SQLite3
# Install Rust from https://rustup.rs
# Then build
git clone https://github.com/klt-mm/llm-tui.git
cd llm-tui
cargo build --release
# Binary will be at .\target\release\llm-tui.exe

Configuration

After installation, create a configuration file at ~/.config/llm-tui/config.toml:

[provider]
base_url = "http://localhost:8080/v1"
api_key = "your-api-key-here"

[generation]
temperature = 0.7
top_p = 0.9
max_tokens = 2048

[context]
max_tokens = 4096
reserve_for_response = 1024

Environment Variables

You can also configure LLM-TUI using environment variables:

  • LLM_TUI_BASE_URL - Provider base URL
  • LLM_TUI_API_KEY - API key
  • LLM_TUI_DATABASE_URL - Database path (default: ./llm-tui.db)
  • RUST_LOG - Log level (default: llm_tui=info)

Uninstallation

To uninstall LLM-TUI:

# If installed via script
curl -fsSL https://raw.githubusercontent.com/klt-mm/llm-tui/main/uninstall.sh | bash

# Or manually
sudo rm /usr/local/bin/llm-tui
rm -rf ~/.config/llm-tui
rm -f ~/llm-tui.db

Verify Installation

Run the following command to verify your installation:

llm-tui --version

You should see the version number (1.0.2 or later).
