Usage Guide

Getting Started

Launch LLM-TUI by running:

llm-tui

The application will create a SQLite database in the current directory (or use the path specified in DATABASE_URL).

Interface Overview

LLM-TUI has a three-panel layout:

  • Left Panel: Conversation sidebar - list and manage conversations
  • Center Panel: Chat view - display messages and streaming responses
  • Bottom Panel: Input area - type messages and commands
  • Top Bar: Status bar - shows provider, model, and metrics

Basic Workflow

1. Start a Conversation

Press Ctrl+N to create a new conversation, or select an existing one from the sidebar.

2. Send a Message

Type your message in the input area and press Enter to send. The response will stream in real-time.

3. Cancel Generation

If you want to stop the current generation, press Alt+C.

4. Retry

To retry the last generation, press Ctrl+R.

Advanced Features

Command Palette

Press Ctrl+K to open the command palette. Type to filter commands, then press Enter to execute.

Available commands:

  • New Conversation
  • Search
  • Prompt Picker
  • Prompt List
  • Select Model
  • Select Provider
  • Generation Settings
  • Branch History
  • Test Connection
  • Keyboard Shortcuts
  • Quit

Prompt Management

LLM-TUI includes a powerful prompt library:

  • Ctrl+P - Open prompt picker to select and use a prompt
  • Ctrl+L - Open prompt list to manage prompts

In the prompt list, you can:

  • n - Create new prompt
  • e - Edit selected prompt
  • d - Delete selected prompt
  • Enter - Use selected prompt

Prompt Variables

Prompts can include variables using {{variable_name}} syntax. When you use a prompt with variables, you'll be prompted to fill in the values.

Write a {{language}} function that {{action}}.
Make sure to include {{requirements}}.

Prompt Tags

Organize prompts with tags for easy filtering and searching.

Search

Press Ctrl+F or / (when input is empty) to open search. Search across:

  • Messages in all conversations
  • Prompt names and content

Use ↑/↓ to navigate results and Enter to open.

Branching

LLM-TUI supports conversation branching:

  • Ctrl+B - Open branch history view
  • Select a message and press Enter to edit as branch
  • The edited message will be copied to input
  • Sending creates a new branch from that point

Branch indicators (↩) show message relationships in the chat view.

Tool Calling

If your provider supports tool calling, LLM-TUI can execute tools automatically:

  • shell - Execute shell commands
  • read_file - Read file contents
  • write_file - Write to files
  • list_directory - List directory contents

Tool calls and results are displayed in the chat view with 🛠️ icons.

Vision Support

Attach images to your messages for vision-capable models:

/image /path/to/image.png

You can attach multiple images. They'll be sent with your next message.

The status bar shows the number of attached images.

Generation Settings

Press Ctrl+G to adjust generation parameters:

  • Temperature - Controls randomness (0.0-2.0)
  • Top P - Nucleus sampling (0.0-1.0)
  • Max Tokens - Maximum response length

Leave fields empty to use provider defaults.

Context Management

LLM-TUI automatically manages context within token budgets:

  • Status bar shows token usage (e.g., "1.2k/4k tok")
  • System prompt is always included
  • Most recent messages are prioritized
  • Oldest messages are dropped when over budget

Model and Provider Selection

Switch between models and providers:

  • Ctrl+M - Cycle through available models
  • 1-9 - Select model by number
  • Command palette - "Select Provider" to switch providers

Configuration

Configuration file location: ~/.config/llm-tui/config.toml

[provider]
base_url = "http://localhost:8080/v1"
api_key = "your-api-key"

[generation]
temperature = 0.7
top_p = 0.9
max_tokens = 2048

[context]
max_tokens = 4096
reserve_for_response = 1024

Tips and Best Practices

  • Use Ctrl+K for quick access to any feature
  • Create prompts for common tasks to save time
  • Use tags to organize your prompt library
  • Leverage branching to explore different conversation paths
  • Monitor token usage in the status bar to optimize context
  • Use Alt+C to cancel long generations
  • Test your connection with Ctrl+T if you encounter issues

Troubleshooting

Connection Issues

If you can't connect to your provider:

  • Check your configuration file
  • Verify the provider is running
  • Use Ctrl+T to test the connection
  • Check the error message in the status bar

Slow Performance

  • Reduce max_tokens in generation settings
  • Lower the context budget in configuration
  • Check your provider's performance

Database Issues

  • Ensure the database file is writable
  • Check disk space
  • Try deleting and recreating the database
